# CO2 Router Site

This repository is the public-facing marketing site for CO2 Router. It also
ships a sandbox-only live demo that uses the real ecobe-mvp decision flow
through the local site route.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- TanStack Query

## Live Demo Architecture

The public live demo is intentionally narrow:

public browser -> co2router-site `/api/decision` -> ecobe-mvp -> decision response

The flow works like this:

1. The site generates a sandbox demo job in the browser.
2. The live page posts that job to the local `/api/decision` route.
3. The local route proxies the request to ecobe-mvp.
4. ecobe-mvp returns the real decision response.
5. The live page renders that response as the public demo feed.

This demo is sandbox-only.
It uses demo jobs generated by the site.
It does not use private customer data.
It does not call `ecobe-engine-claude` directly from the website.

### Environment

The request path uses the broker base URL resolved by `src/lib/broker-url.ts`.
The repo already recognizes these environment variables for that boundary:

- `ECOBE_API_URL`
- `MCP_API_URL`
- `NEXT_PUBLIC_MCP_API_URL`
- `ECOBE_MVP_URL`
- `NEXT_PUBLIC_ECOBE_API_URL`

The browser always calls `/api/decision`. That route forwards to the configured
broker base URL.

### Contract assumptions

The live page normalizes these decision response fields when they are present:

- `job_id` or `jobId`
- `timestamp`
- `carbon_value`, `carbonValue`, `carbon_intensity`, or `carbonIntensity`
- `action` or `decision`
- `proof_id`, `proofId`, `proof_hash`, or `proofHash`
